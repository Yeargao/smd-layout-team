# Proposed interface v1 (agree before coding)
ES modules; pure graph data and separate geometry. Document: {version:1, graph:{nodes:[{id,parentId}], regions:[{id,parentId}], edges:[{id,source,target}]}, layout:{positions:{[id]:{x,y}}, regions:{[id]:{x,y,width,height,collapsed}}, routes:{[edgeId]:{waypoints:[{x,y}],manual}}}}. IDs unique across states/regions; parents are region IDs or null; hierarchy acyclic; edge endpoints are actual state IDs. Coordinates global SVG units; position is node center, region x/y is upper left. All modules agree before changing schema. Only visibleGraph projects edge endpoints. Never overwrite original endpoints. Loading does not invoke initialLayout.
P01: src/layout.js exports layoutLevel(ids,edges,sizes) -> {positions,w,h}; positions here are upper-left local coordinates; sizes {w,h}. P02: src/hierarchy.js initialLayout(graph), visibleGraph(doc), toggleRegion(doc,id), moveNode(doc,id,x,y); src/routing.js edgePoints(edge,visible,layout). P03: src/editor.js, src/storage.js, index.html. Add tests and fixtures in own paths. Shared API changes require discussion and review.
